## 2. Remediation Verification Details (P1-FE-01-R1)

The following architect-requested defects were corrected:

1. **R1-01 — End-to-End Deadline Enforced across Response Lifecycle:**
   - Refactored `fetchJsonWithDeadline` in `apps/web/src/lib/api.ts` so the 5-second deadline timer remains active throughout both header retrieval and full `response.json()` body consumption.
   - If response body streams or stalls indefinitely, the timer triggers `AbortController.abort()`, cleanly returning `{ kind: 'timeout' }`.
   - External cancellation (`options.signal`) cleanly returns `{ kind: 'aborted' }` without throwing unhandled exceptions.
   - All timers and signal listeners are guaranteed cleared in `finally` blocks on all exit paths.

2. **R1-02 — Strict Readiness Matrix Enforcement:**
   Implemented the exact status/body truth matrix:
   - `HTTP 200` + `ready: true`  -> `ready`
   - `HTTP 503` + `ready: false` -> `not_ready`
   - `HTTP 200` + `ready: false` -> `invalid` (contradictory)
   - `HTTP 503` + `ready: true`  -> `invalid` (contradictory)
   - `Other status` (500, 502, 504, 404) -> Controlled `unavailable` state
   - `200` or `503` + Malformed JSON -> `invalid`

3. **R1-03 — Corrected Health UI Reporting:**
   - Vite proxy failure (HTTP 502 Bad Gateway when Express is stopped) and server 500 errors now accurately display "Backend unavailable" rather than misleadingly claiming an "Invalid API response schema".
   - Contradictory responses are never displayed as healthy.
   - "Backend not ready" is rendered only for authentic HTTP 503 with `ready: false`.
   - Transport failures (connection refused / failed to fetch) are accurately rendered as "Backend offline".

4. **R1-04 — Strengthened Automated Test Coverage:**
   - Created dedicated API unit tests in `apps/web/src/tests/api.test.ts` (10 tests).
   - Augmented `apps/web/src/tests/HealthStatus.test.tsx` (12 tests) with fake timer deadline assertions and contradictory readiness rejections.
   - Total monorepo tests increased from 23 to 38 (contracts: 9, web: 29). 100% passing.
