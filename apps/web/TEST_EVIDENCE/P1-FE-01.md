## 3. Failure-Path Test Evidence

Unit tests explicitly cover the following negative / degraded conditions:
1. **Network failure / Backend offline:** `globalThis.fetch` rejection is caught without unhandled rejection; UI displays "Backend offline" and provides the network error explanation.
2. **Readiness HTTP 503:** Server is reachable, but readiness returns HTTP 503 with `{ data: { ready: false } }`; UI correctly distinguishes this from offline by displaying "Backend online" alongside "Backend not ready (HTTP 503 received: Server is running but required dependencies are not ready)".
3. **Malformed API JSON:** Valid HTTP 200 response with malformed JSON or invalid schema; Zod validation safely catches discrepancy, displaying "Invalid API response" without crashing.
4. **Slow request / Unmount cleanup:** When requests take longer than 5s or component unmounts mid-request, `AbortController` cancellation cleans up listeners and avoids setState warnings on unmounted components.
5. **Unauthorized Admin Access:** Direct navigation to `/admin` renders 404 Page Not Found with an explicit notice that no administrative interface is accessible without verified authentication.
