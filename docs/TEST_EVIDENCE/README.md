# Test Evidence & Verification Records

This directory contains real executed test evidence, terminal outputs, exit codes, and verification audits for completed atomic tasks.

## Guidelines

- Every task handoff must produce an evidence file named `<TASK_ID>.md` (e.g. `P1-FND-01.md`).
- Records must reflect actual commands executed in the local environment.
- Falsifying or simulating test passes via `exit 0` or suppressing errors is strictly prohibited.
- Evidence records document pass/fail status, security scanning results, known limitations, and unresolved technical blockers.
