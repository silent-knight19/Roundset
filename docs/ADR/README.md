# Architecture Decision Records (ADR)

This directory contains formal, versioned Architecture Decision Records for the Roundset platform.

## Policy

- Only the **Principal Software Architect** (ChatGPT) is authorized to author and approve new ADRs.
- Implementation agents may propose technical findings or report architectural conflicts, but are strictly prohibited from inventing or approving ADRs autonomously.
- Approved decisions are binding across all workspace packages and implementation phases.
